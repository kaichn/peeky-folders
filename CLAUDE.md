# Peeky Folders: notes for Claude

A macOS Quick Look extension (plus a small host app) that previews folders and archives. AppKit,
built with `swiftc` from `build.sh`; there's no Xcode project. Repo: github.com/kaichn/peeky-folders.

## Building

- `./build.sh install` builds and replaces `~/Applications/Peeky Folders.app`, then launches it
  hidden once so Quick Look picks up the new extension.
- Bundle IDs: `com.charl.PeekyFolders` and `com.charl.PeekyFolders.Preview`. Changing them resets
  the preview's settings, which live in the extension's sandbox container.
- The two Info.plists must carry the same version; `build.sh` checks this.

## Releases

1. Bump `CFBundleShortVersionString` and `CFBundleVersion` in **both** `Resources/App-Info.plist`
   and `Resources/Extension-Info.plist` with `sed`. PlistBuddy reformats the whole file.
2. Run `./build.sh release`. It builds a universal app and writes `dist/PeekyFolders-<version>.zip`
   plus a `.sha256`.
3. Commit, `git tag -a v<version>`, `git push --follow-tags`.
4. `gh release create v<version> dist/PeekyFolders-<version>.zip dist/PeekyFolders-<version>.zip.sha256`.
   Release notes list only what changed. The README covers install and Gatekeeper.
   The user picks version numbers.

## Icon

- `Resources/AppIcon.icon` is generated by `scripts/make-icon-layers.py` (Icon Composer format).
  Edit the script, rerun it, and render a preview with Icon Composer's `ictool`
  (inside `Icon Composer.app/Contents/Executables`) before installing.
- The current design is the user's: a frosted glass folder with two more fanned out behind it,
  on the Big Sur Finder blue. A translucent heart and lines in Apple systemPink (`#FF2D55`).
  Don't redesign it without asking.

## Testing

- `PeekyFolders --snapshot <folder-or-archive> out.png [list|icons]` renders the browser to a PNG,
  and `PeekyFolders --welcome-snapshot out.png` renders the welcome window. Neither needs Screen
  Recording permission.
- Screenshots in `docs/` use a demo folder made from macOS's sample pictures in
  `/Library/User Pictures`, not the user's files.
